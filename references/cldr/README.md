# Unicode CLDR alphabet data

`languages.json` contains main, auxiliary, and index exemplar extracts from ten
official CLDR 48 locale files, with source URLs and SHA-256 hashes. The original
Unicode data is licensed under the included `LICENSE.txt`. It does not change the
license of the original SEIReader font or the separately licensed reference fonts.

The normal build/audit uses the pinned local JSON and does not download CLDR data.
No reference glyph outlines or font programs were imported from CLDR or code charts.
